# Superstore Sales & Profitability Analysis

## 📊 Dataset Description

This project uses the **Sample Superstore dataset**, which contains information about customer orders, products, sales, discounts, shipping, and profitability.

The dataset contains **9,994 records and 21 columns**. Each record represents an order line containing information about the customer, product, location, shipping, sales, and profit.

Before performing any analysis, the raw dataset will be inspected and cleaned to ensure that the data is suitable for analysis.

## 🗂️ Data Dictionary

The dataset contains the following columns:

| Column          | Description                                                   |
| --------------- | ------------------------------------------------------------- |
| `Row ID`        | Unique identifier for each row in the dataset                 |
| `Order ID`      | Unique identifier for a customer order                        |
| `Order Date`    | Date when the order was placed                                |
| `Ship Date`     | Date when the order was shipped                               |
| `Ship Mode`     | Shipping method used for the order                            |
| `Customer ID`   | Unique identifier assigned to the customer                    |
| `Customer Name` | Name of the customer                                          |
| `Segment`       | Customer segment, such as Consumer, Corporate, or Home Office |
| `Country`       | Country associated with the order                             |
| `City`          | City associated with the order                                |
| `State`         | State associated with the order                               |
| `Postal Code`   | Postal code associated with the location                      |
| `Region`        | Geographic region of the order                                |
| `Product ID`    | Unique identifier for the product                             |
| `Category`      | Main category of the product                                  |
| `Sub-Category`  | More specific classification of the product                   |
| `Product Name`  | Name of the product purchased                                 |
| `Sales`         | Revenue generated from the order                              |
| `Quantity`      | Number of units purchased                                     |
| `Discount`      | Discount applied to the order                                 |
| `Profit`        | Profit generated from the order                               |
